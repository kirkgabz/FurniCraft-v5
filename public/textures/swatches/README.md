# Material swatches

The small surface photos the material and colour boxes show
(`components/design/material-skin.tsx`). Built once from the sources below
and committed as static files; replace a file to change a surface.

- `<folder>.jpg` — the studio's own scan from `public/textures/<folder>/diffuse.jpg`,
  downsized and brightened, for finishes rendered from that scan.
- `<name>-detail.jpg` — a surface photo in greyscale, centred on mid-grey, laid
  over a finish's own colour.
